# C18 醫療群會員急診住院查詢（`ReferralMember`）

## 1. 功能定位

- 樹狀選單 Key：`C18`
- 顯示名稱：醫療群會員急診住院查詢
- 核心程序：`module/OpdAccRpt/Module1.bas` 的 `ReferralMember`
- 呼叫入口：`source/OpdAccRpt/FrmTreeView.frm` 的 `CmdPreview_Click`
- 輸入：起始日、迄止日、門急診／住院來源
- 輸出：Excel 活頁簿；不寫入 Access 暫存表，也不使用傳入的 CrystalReport 物件
- 日期格式：程式預期民國 7 碼 `YYYMMDD`，例如 `1150807`

## 2. 程式入口與畫面流程

`Form_Load` 將 C18 建立為根節點 `R` 的直屬子節點：

```vb
Set nodX = TreeView1.Nodes.Add("R", tvwChild, "C18", "醫療群會員急診住院查詢")
```

使用者點選 C18 時，`TreeView1_NodeClick` 顯示兩個來源選項 `optSource(0)`、`optSource(1)`，其餘批價時段、科別、診間、醫令碼等條件均停用。按下預覽時：

```vb
If optSource(0).Value = True Then
    strOpdIpd = "O"
ElseIf optSource(1).Value = True Then
    strOpdIpd = "I"
End If

Case "C18"
    Call ReferralMember(Trim(TxtDate_Start.Text), _
                        Trim(TxtDate_End.Text), CrystalReport)
```

`strOpdIpd` 是全域變數，用來動態切換表名：

| 值 | 實際就醫主檔 | 報表語意 |
| --- | --- | --- |
| `O` | `OpdBasicTbl` | 急診（程式再限定診間 `0000`） |
| `I` | `IpdBasicTbl` | 住院 |

畫面共用檢核只確認起訖日期不為空且起日不大於迄日。`ReferralMember` 本身沒有呼叫 `IsDate7`，也沒有再次驗證日期字串，移植時宜補上嚴格的 7 碼民國日期驗證。

## 3. 實際 SQL（依原始碼展開）

以下以 `{BasicTbl}` 代表依來源選出的 `OpdBasicTbl` 或 `IpdBasicTbl`，`:startDate`、`:endDate` 及 `:memberYear` 表示原程式直接串接的字串參數：

```sql
SELECT /*+ use_merge(b,f) */
       f.chhospno                         AS 診院代碼,
       h.chname                           AS 診院名稱,
       b.chop1pid                         AS 身分證號,
       f.chcase                           AS 收案類別,
       RTRIM(b.chop1pname)                AS 病患姓名,
       RTRIM(b.chop1mrno)                 AS 病歷號,
       s.chsecname                        AS 就診科別,
       RTRIM(b.chop1ebid)                 AS 病床號,
       RTRIM(b.chop1drname)               AS 主治醫師,
       b.chop1date                        AS 住院日期,
       SUBSTR(b.chop1eoutdate, 1, 7)      AS 出院日期,
       b.chop1icd1                        AS 診斷碼1,
       b.chop1icd2                        AS 診斷碼2,
       b.chop1icd3                        AS 診斷碼3,
       i1.chicd9cname                     AS 診斷碼名稱1,
       i2.chicd9cname                     AS 診斷碼名稱2,
       i3.chicd9cname                     AS 診斷碼名稱3,
       t.chagree                          AS 網路同意,
       t.chwhole                          AS 完整回覆,
       CASE
         WHEN RTRIM(b.chop1tranin) IS NOT NULL
          AND b.chop1tranout = 'N'
          AND b.chop1sec <> '0340' THEN '轉入'
         WHEN RTRIM(b.chop1tranin) IS NOT NULL
          AND b.chop1tranout = 'Y'
          AND b.chop1sec <> '0340' THEN '轉出'
         ELSE ''
       END                                AS 轉診註記
FROM {BasicTbl} b
-- 只有急診分支才加入：
JOIN OpdRegPtnTbl r
  ON b.chop1date = r.chop0date
 AND b.chop1time = r.chop0time
 AND b.chop1room = r.chop0room
 AND b.intop1no  = r.intop0no
JOIN GenReferralMemberTbl f
  ON b.chop1pid = f.chid
JOIN GenSectionTbl s
  ON b.chop1sec = s.chsecno
LEFT JOIN OpdTFHospitalTbl h
  ON f.chhospno = h.chhospno
LEFT JOIN GenICD9Tbl i1
  ON b.chop1icd1 = i1.chicd9no
LEFT JOIN GenICD9Tbl i2
  ON b.chop1icd2 = i2.chicd9no
LEFT JOIN GenICD9Tbl i3
  ON b.chop1icd3 = i3.chicd9no
LEFT JOIN OpdTFTbl t
  ON b.chop1date = t.chop1date
 AND b.chop1time = t.chop1time
 AND b.chop1room = t.chop1room
 AND b.intop1no  = TO_NUMBER(t.intop1no)
WHERE b.chop1date BETWEEN :startDate AND :endDate
  AND f.chyear = :memberYear
-- 住院分支追加：
  AND (b.chOp1ClmFlg <> 'D' OR RTRIM(b.chOp1ClmFlg) IS NULL)
-- 急診分支改為追加：
  AND b.chop1room = '0000'
  AND r.chop0dc = '0';
```

注意：上面將兩個互斥分支並列以利閱讀，實際執行時不會同時存在。`memberYear` 是 `Left(strSDate, 3)`，只依起始日的民國年度匹配會員名單。

## 4. 資料表與欄位角色

| 資料表 | Join 型態 | 用途 |
| --- | --- | --- |
| `OpdBasicTbl` / `IpdBasicTbl` | 主表 | 就醫日期、病患、病歷、科別、醫師、床號、出院日、診斷、轉診旗標 |
| `OpdRegPtnTbl` | 急診限定 inner join | 確認對應掛號資料並排除退掛／取消資料 (`chop0dc='0'`) |
| `GenReferralMemberTbl` | inner join | 以身分證號認定醫療群會員，提供會員年度、診所代碼與收案類別 |
| `GenSectionTbl` | inner join | 科別代碼轉科別名稱；缺少對照者會被排除 |
| `OpdTFHospitalTbl` | left join | 診所代碼轉診所名稱；沒有主檔仍保留就醫資料 |
| `GenICD9Tbl` × 3 | left join | 前三個診斷碼轉中文名稱 |
| `OpdTFTbl` | left join | 網路轉診的同意與完整回覆狀態 |

核心會員判斷是 `b.chop1pid = f.chid` 加上 `f.chyear = Left(strSDate, 3)`，不是以病歷號或診所代碼判斷。

## 5. 急診與住院分支

### 5.1 急診 (`strOpdIpd = "O"`)

1. 主檔為 `OpdBasicTbl`。
2. 必須成功連到 `OpdRegPtnTbl`。
3. `b.chop1room='0000'` 被當作急診條件。
4. `r.chop0dc='0'` 排除已取消／退掛資料。
5. Excel 工作表名稱為 `急診 {起日}~{迄日}`。

### 5.2 住院 (`strOpdIpd = "I"`)

1. 主檔為 `IpdBasicTbl`，不 join `OpdRegPtnTbl`。
2. 排除 `chOp1ClmFlg='D'`，但保留旗標為 NULL 或尾端空白者。
3. Excel 工作表名稱為 `住院 {起日}~{迄日}`。

查詢欄位仍命名為「住院日期／出院日期／病床號」，即使執行急診分支也不改欄名；這是既有 Excel 介面的行為。

## 6. 轉診註記規則

`轉診註記` 完全由就醫主檔的 `chop1tranin`、`chop1tranout`、`chop1sec` 計算：

| 條件 | 結果 |
| --- | --- |
| `chop1tranin` 非空、`chop1tranout='N'`、科別不是 `0340` | 轉入 |
| `chop1tranin` 非空、`chop1tranout='Y'`、科別不是 `0340` | 轉出 |
| 其他 | 空字串 |

原註解指出 `0340` 是資源共享科別，因此刻意不標示轉入／轉出。值得注意的是兩個分支都要求 `chop1tranin` 非空；即使 `chop1tranout='Y'`，若轉入院所欄位空白仍不會標成轉出。

## 7. Excel 輸出流程

1. 先呼叫 `subIsExcel2000`，實際行為是以 `CreateObject("Excel.Application")` 測試 Excel 是否可啟動；名稱雖保留 Excel 2000，並未限定版本。
2. 透過 `CGetData.GetDataRS(SQL, ..., mADOCn)` 取得 ADO Recordset。
3. 有資料才呼叫 `subExcel`；無資料顯示「查無資料!!」。
4. `subExcel` 建立單一 worksheet，第一列使用 SQL alias 作為欄名，第二列起以 `CopyFromRecordset` 一次匯入。
5. `strFilePath` 傳入空字串，所以不自動存檔、不關閉 Excel，而是將可見的未儲存活頁簿交給使用者。
6. `ReferralMember` 的第三個 `CrystalReport` 參數從未使用，屬歷史介面殘留。

## 8. 重要限制與風險

- **SQL Injection／引號風險**：日期直接串入 SQL；雖畫面通常只輸入數字，仍應改為參數化查詢。
- **跨年度查詢**：會員年度固定取起日的前三碼。若日期跨民國年度，後一年度仍只匹配起始年度名單，可能漏資料或套用錯誤會員版本。
- **ICD 版本**：只連 `GenICD9Tbl`，即使資料年代已使用 ICD-10，也不會查 `GenICD10Tbl`。
- **重複列**：程式沒有 `DISTINCT`。若會員表同年度同身分證有多筆，或 `OpdTFTbl` 同一就醫鍵有多筆，輸出會倍增。
- **inner join 排除**：會員、科別對照缺失時整筆就醫資料消失，不只是名稱為空。
- **`TO_NUMBER(t.intop1no)`**：若 `OpdTFTbl.intop1no` 含非數字字元，Oracle 可能使整個查詢失敗。
- **沒有 ORDER BY**：Excel 列順序不保證穩定。
- **錯誤處理不足**：程序沒有 `On Error` 清理區塊；Oracle、ADO 或 Excel 例外時物件可能未正常釋放。
- **日期語意**：住院與急診都用 `chop1date` 篩選；不會依出院日找出「期間內出院」或依轉診發生日篩選。

## 9. 維護／移植時的等價實作建議

1. 將門急診與住院 SQL 拆成清楚的兩個查詢，避免動態表名字串。
2. 起訖日期轉成受控的民國日期值或明確的西元日期，再參數化傳入。
3. 明確決定跨年度會員名單的規則：依每筆就醫年度 join，或禁止跨年度。
4. 對 `OpdTFTbl.intop1no` 先做安全數字轉換，並確認是否應先去重。
5. 保持 21 個 Excel 欄位名稱與順序，因既有下游可能依欄位位置處理。
6. 以相同條件比較 VB6 與新程式的總筆數、會員身分證、診所、就醫鍵、診斷及轉診註記。
